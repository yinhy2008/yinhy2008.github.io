# OpenClaw 双角色聊天 APP — PRD（产品需求文档）

> 项目：金融顾问 vs 谨慎客户 双角色对话系统
> 版本：v1.0 · 2026-07-24
> 平台：OpenClaw（docs.openclaw.ai）

---

## 1. 背景与目标

### 1.1 背景

模块三下午实验课加分作业（最高 +10 分）要求用 OpenClaw 制作双角色聊天 APP。本 PRD 定义一个金融场景的双角色对话系统：**持牌理财顾问**与**保守型谨慎客户**就"推荐一只适合客户风险偏好的理财产品"这一明确任务，在受控轮数内完成一次完整对话。

### 1.2 目标

- 两个角色**身份不同、目标不同、禁止事项不同**，通过消息交替传递推进对话
- 围绕一个明确任务（推荐理财产品 + 风险评估）
- 设置最大轮数与停止条件，**不允许无限循环**
- 处理常见异常（空消息、超时、角色违规）

### 1.3 非目标

- 不接入真实金融数据或行情
- 不做产品推荐的真实性担保（仅模拟对话流程）
- 不做多轮记忆持久化（单次会话即结束）
- 不做多 Agent 并行（仅严格交替）

---

## 2. 角色定义

### 2.1 角色 1：金融顾问（Advisor）

| 维度 | 内容 |
|---|---|
| **身份** | 持牌理财顾问，5 年经验，代表产品方 |
| **目标** | 在 6 轮内为客户端推荐**一只**适合其风险偏好的理财产品，并完成风险评估 |
| **允许行为** | 询问客户年龄/风险偏好/投资期限；推荐一只产品；解释产品风险等级与费用结构；回答客户疑问 |
| **禁止事项** | ① 不得承诺或暗示具体收益率；② 不得夸大产品效果或使用"保本""稳赚"等绝对化用语；③ 不得推荐超过客户风险等级的产品；④ 不得在客户未完成风险评估前直接推荐产品 |

### 2.2 角色 2：谨慎客户（Cautious Client）

| 维度 | 内容 |
|---|---|
| **身份** | 50 岁，临近退休，保守型投资者，本金 50 万 |
| **目标** | 在 6 轮内就顾问推荐的产品提出 3 个关键问题（风险等级 / 费用结构 / 适合性），最终决定是否购买 |
| **允许行为** | 询问产品风险等级、费用、期限；要求顾问解释不清楚的术语；最终回答"确认购买"或"放弃购买" |
| **禁止事项** | ① 不得未问清风险就购买；② 不得忽略费用结构；③ 不得在顾问未完成风险评估时催促推荐；④ 不得询问与理财无关的内容 |

## 3. 任务定义

### 3.1 明确任务

**任务描述**：金融顾问为谨慎客户推荐一只适合其风险偏好（保守型）的理财产品，客户通过 3 个关键问题（风险等级、费用结构、适合性）确认产品是否适合自己，最终给出购买决策。

### 3.2 任务边界

- 推荐产品**仅限 1 只**（避免多产品对比导致对话发散）
- 客户提问**仅限 3 个关键维度**（风险 / 费用 / 适合性）
- 对话**不超过 6 轮**（1 轮 = 顾问发言 + 客户发言）

### 3.3 推荐产品范围（顾问可选）

| 产品 | 风险等级 | 适合保守型 |
|---|---|---|
| 货币市场基金 | R1（低风险） | ✅ 适合 |
| 短期债券基金 | R2（中低风险） | ✅ 适合 |
| 混合型基金 | R3（中风险） | ⚠️ 需客户确认 |
| 股票型基金 | R4（中高风险） | ❌ 不适合 |
| 结构性存款（保本型） | R1-R2 | ✅ 适合 |

## 4. 对话流程

### 4.1 标准流程（6 轮内）

| 轮次 | 顾问（角色 1） | 客户（角色 2） |
|---|---|---|
| 1 | 自我介绍 + 询问客户基本信息（年龄/风险偏好/投资期限） | 回答基本信息，明确"保守型 + 3 年期限" |
| 2 | 完成风险评估，推荐一只 R1 或 R2 产品 | 提问 1：产品风险等级是 R 几？ |
| 3 | 回答风险等级（R1/R2），解释风险含义 | 提问 2：费用结构（管理费 / 托管费 / 赎回费）？ |
| 4 | 列出费用明细 | 提问 3：这个产品适合我这个年纪吗？ |
| 5 | 解释适合性（年龄匹配 / 风险匹配） | 给出决策："确认购买"或"放弃购买" |
| 6 | 确认订单 / 记录放弃原因 + 结束语 | 结束语 |

### 4.2 停止条件

对话在以下任一条件触发时立即结束：

1. **最大轮数**：达到 6 轮（12 条消息）
2. **客户确认购买**：客户在第 5 轮或之前说"确认购买"
3. **客户放弃购买**：客户说"放弃购买"或"不买了"
4. **人工停止**：用户点击"停止对话"按钮
5. **角色违规**：顾问承诺收益 / 客户未问就买 → 系统干预，对话终止

### 4.3 异常处理

| 异常 | 处理方式 |
|---|---|
| 空消息 | 系统提示"请输入有效内容"，不消耗轮数 |
| 消息超时（>60 秒） | 系统提示"响应超时，请重试"，不消耗轮数 |
| 顾问违反禁止项（如承诺收益） | 系统警告 + 该消息作废 + 重新生成 |
| 客户询问无关内容 | 顾问礼貌引导回主题，消耗轮数 |
| 角色发言顺序错乱 | 系统强制纠正为交替顺序 |

## 5. 验收标准

| AC | 描述 | 验证方式 |
|---|---|---|
| AC1 | 两个角色身份、目标、禁止事项均不同且明确 | 检查 PRD 第 2 节 |
| AC2 | 消息严格交替传递（A→B→A→B...） | 运行 Demo 截图 |
| AC3 | 对话围绕明确任务（推荐 1 只产品 + 3 个问题） | 运行 Demo 截图 |
| AC4 | 最大 6 轮限制生效 | 运行到第 6 轮自动停止 |
| AC5 | 至少 1 个停止条件可触发（如客户说"确认购买"提前结束） | Demo 中演示 |
| AC6 | 异常处理可运行（如空消息提示） | Demo 中演示 |
| AC7 | 不出现无限循环 | 运行 6 轮后强制结束 |

## 6. 范围边界

- 本 PRD 仅定义对话逻辑与角色规则，不涉及 OpenClaw 平台的具体配置步骤（详见 `design.md`）
- 产品推荐内容为模拟数据，不构成真实投资建议
- 对话内容不存储，单次会话即结束
