## 1. 系统架构

### 1.1 整体架构

```
┌─────────────────────────────────────────────┐
│            OpenClaw 平台运行时              │
│                                             │
│  ┌─────────────┐       ┌─────────────┐      │
│  │  角色 1     │       │  角色 2     │      │
│  │ 金融顾问    │ ←──→  │ 谨慎客户    │      │
│  │ (Advisor)   │       │ (Client)   │      │
│  └─────────────┘       └─────────────┘      │
│         ↕                      ↕            │
│  ┌──────────────────────────────────────┐   │
│  │        消息调度器（Controller）      │   │
│  │  - 严格交替（A→B→A→B）              │   │
│  │  - 轮数计数器（max 6）              │   │
│  │  - 停止条件检查                     │   │
│  │  - 异常处理                         │   │
│  └──────────────────────────────────────┘   │
│                                             │
└─────────────────────────────────────────────┘
```

### 1.2 消息流

```
[START]
  │
  ▼
顾问发言（轮 1A）
  │
  ▼
客户发言（轮 1B）  ← 第 1 轮完成
  │
  ▼
检查停止条件 ──(触发)──→ [END]
  │
  ▼(未触发)
顾问发言（轮 2A）
  │
  ▼
客户发言（轮 2B）  ← 第 2 轮完成
  │
  ▼
检查停止条件 ──(触发)──→ [END]
  │
  ▼(未触发)
  ...（重复至第 6 轮）
  │
  ▼
[END]（强制结束）
```

## 2. 角色配置

### 2.1 角色 1：金融顾问

**System Prompt 示例**：

```
你是一名持牌理财顾问，5 年从业经验。你的任务是为一位置近退休的保守型客户推荐一只适合其风险偏好的理财产品。

你的目标：
- 询问客户基本信息（年龄、风险偏好、投资期限）
- 完成风险评估后推荐一只 R1 或 R2 风险等级的产品
- 回答客户关于风险等级、费用结构、适合性的问题

你必须遵守的禁止事项：
1. 不得承诺或暗示具体收益率（如"年化 5%"）
2. 不得使用"保本""稳赚""零风险"等绝对化用语
3. 不得推荐 R3 及以上风险等级的产品给保守型客户
4. 不得在客户未完成风险评估前直接推荐产品

对话规则：
- 每次只发一条消息，然后等待客户回复
- 不得连续发言
- 如果客户问无关问题，礼貌引导回主题
```

### 2.2 角色 2：谨慎客户

**System Prompt 示例**：

```
你是王先生，50 岁，临近退休，保守型投资者，可用本金 50 万，投资期限 3 年。

你的目标：
- 配合顾问完成基本信息确认
- 就顾问推荐的产品提出 3 个关键问题：
  1. 产品的风险等级是 R 几？
  2. 费用结构（管理费、托管费、赎回费）？
  3. 这个产品适合我这个年纪吗？
- 最终给出"确认购买"或"放弃购买"的决定

你必须遵守的禁止事项：
1. 不得未问清风险就购买
2. 不得忽略费用结构
3. 不得在顾问未完成风险评估时催促推荐
4. 不得询问与理财无关的内容（如闲聊天气）

对话规则：
- 每次只发一条消息，然后等待顾问回复
- 不得连续发言
```

## 3. 停止条件设计

### 3.1 停止条件矩阵

| 条件 ID | 触发方式 | 系统响应 |
|---|---|---|
| S1 | 轮数计数器达到 6 | 显示"已达最大轮数，对话结束" + 结束 |
| S2 | 客户消息包含"确认购买" | 显示"客户已确认购买，对话结束" + 结束 |
| S3 | 客户消息包含"放弃购买"或"不买了" | 显示"客户放弃购买，对话结束" + 结束 |
| S4 | 用户点击"停止对话"按钮 | 显示"用户手动停止对话" + 结束 |
| S5 | 顾问违反禁止项（检测到"保本""稳赚""年化 X%"等关键词） | 系统警告 + 终止对话 |

### 3.2 停止条件实现逻辑（伪代码）

```python
def check_stop_condition(round_count, client_msg, advisor_msg, user_action):
    # S1: 最大轮数
    if round_count >= 6:
        return "END", "已达最大轮数，对话结束"

    # S5: 顾问违规（优先级最高）
    violation_keywords = ["保本", "稳赚", "零风险", "年化", "保证收益"]
    if any(kw in advisor_msg for kw in violation_keywords):
        return "END", "顾问违反禁止事项，系统终止对话"

    # S2: 客户确认购买
    if "确认购买" in client_msg:
        return "END", "客户已确认购买，对话结束"

    # S3: 客户放弃购买
    if "放弃购买" in client_msg or "不买了" in client_msg:
        return "END", "客户放弃购买，对话结束"

    # S4: 人工停止
    if user_action == "manual_stop":
        return "END", "用户手动停止对话"

    return "CONTINUE", None
```

## 4. 异常处理设计

### 4.1 异常分类与处理

| 异常 ID | 异常类型 | 检测方式 | 处理方式 | 是否消耗轮数 |
|---|---|---|---|---|
| E1 | 空消息 | 消息长度为 0 或仅空格 | 提示"请输入有效内容" | 否 |
| E2 | 消息超时 | 发言间隔 > 60 秒 | 提示"响应超时，请重试" | 否 |
| E3 | 角色违规 | 关键词检测（见 S5） | 警告 + 终止 | 是（终止） |
| E4 | 发言顺序错乱 | 检查上一条消息发送者 | 强制纠正为交替顺序 | 否 |
| E5 | 客户偏离主题 | 消息不含"风险/费用/适合/购买"等关键词 | 顾问礼貌引导回主题 | 是 |

### 4.2 异常处理逻辑

```python
def handle_exception(msg, last_sender, time_delta):
    # E1: 空消息
    if not msg.strip():
        return "提示：请输入有效内容", False  # 不消耗轮数

    # E2: 超时
    if time_delta > 60:
        return "提示：响应超时，请重试", False  # 不消耗轮数

    # E4: 顺序错乱
    if last_sender == "advisor" and current_sender == "advisor":
        return "提示：请等待客户回复", False  # 不消耗轮数

    # E5: 客户偏离主题（非关键词）
    if current_sender == "client":
        keywords = ["风险", "费用", "适合", "购买", "放弃", "确认"]
        if not any(kw in msg for kw in keywords):
            return "顾问：我们还是回到产品讨论吧，您还有其他关于风险或费用的问题吗？", True

    return None, True  # 正常流程
```

## 5. 对话示例（预期运行结果）

### 5.1 正常完成（5 轮结束）

```
[轮 1A] 顾问：您好，我是持牌理财顾问。请问您的年龄、风险偏好和投资期限？
[轮 1B] 客户：我 50 岁，保守型，3 年期限。
[轮 2A] 顾问：根据您的风险评估，我推荐"XX 短期债券基金"（R2 风险等级）。
[轮 2B] 客户：风险等级是 R 几？具体什么含义？
[轮 3A] 顾问：R2 中低风险，波动较小，适合保守型投资者。
[轮 3B] 客户：费用结构是什么？管理费、托管费、赎回费？
[轮 4A] 顾问：管理费 0.3%/年，托管费 0.1%/年，持有满 7 天免赎回费。
[轮 4B] 客户：这个产品适合我这个年纪吗？
[轮 5A] 顾问：适合，50 岁临近退休配置 R2 产品符合年龄与风险匹配原则。
[轮 5B] 客户：确认购买。
[系统] 客户已确认购买，对话结束（5 轮完成）
```

### 5.2 异常终止（顾问违规）

```
[轮 1A] 顾问：您好...（正常）
[轮 1B] 客户：我 50 岁，保守型，3 年期限。
[轮 2A] 顾问：我推荐"XX 短期债券基金"，年化收益 5%，保本！
[系统] 顾问违反禁止事项（"年化收益""保本"），对话终止
```

## 6. OpenClaw 平台配置步骤

### 6.1 创建 Agent

1. 登录 <https://docs.openclaw.ai>
2. 创建新项目 → 选择"双角色对话"模板
3. 配置角色 1（Advisor）：粘贴 PRD 2.1 的 System Prompt
4. 配置角色 2（Client）：粘贴 PRD 2.2 的 System Prompt
5. 设置消息交替模式：`alternating`
6. 设置最大轮数：`max_rounds = 6`
7. 设置停止关键词：`["确认购买", "放弃购买", "不买了"]`
8. 设置违规关键词：`["保本", "稳赚", "零风险", "年化", "保证收益"]`
9. 启用异常处理：空消息 + 超时

### 6.2 运行与验证

1. 启动对话
2. 观察消息严格交替
3. 测试停止条件：在第 5 轮客户说"确认购买" → 应自动结束
4. 测试异常：发送空消息 → 应提示且不消耗轮数

## 7. 风险与限制

| 风险 | 影响 | 缓解 |
|---|---|---|
| OpenClaw 平台对中文支持有限 | 角色理解偏差 | System Prompt 用简洁明确中文 |
| LLM 可能不严格遵守禁止事项 | 出现违规内容 | 违规关键词检测 + 系统干预 |
| 对话偏离任务 | 轮数浪费 | 顾问引导回主题 + 偏题检测 |
| 6 轮不足以完成任务 | 对话未完成强制结束 | 第 6 轮允许"待续"状态 |
