## 一、项目说明

本项目是「金融 AI Agent 暑假集训 · 模块三下午实验课」的加分作业（最高 +10 分），使用 OpenClaw 平台构建一个双角色聊天 APP，模拟"持牌理财顾问"与"保守型谨慎客户"就"推荐一只适合客户风险偏好的理财产品"在受控轮数内完成完整对话。

## 三、双角色概览

### 角色 1：金融顾问（Advisor）

- **身份**：持牌理财顾问，5 年经验
- **目标**：6 轮内为保守型客户推荐一只 R1/R2 产品并完成风险评估
- **禁止**：承诺收益、绝对化用语（"保本""稳赚"）、推荐超风险产品、未评估就推荐

### 角色 2：谨慎客户（Cautious Client）

- **身份**：50 岁，临近退休，保守型，本金 50 万
- **目标**：6 轮内就推荐产品提出 3 个关键问题（风险/费用/适合性），最终决策
- **禁止**：未问就买、忽略费用、催促推荐、偏离主题

---

## 四、停止条件与异常处理

### 停止条件（5 个）

1. 最大 6 轮（12 条消息）
2. 客户说"确认购买"
3. 客户说"放弃购买"/"不买了"
4. 用户手动停止
5. 顾问违反禁止事项（系统终止）

### 异常处理（5 类）

1. 空消息 → 提示重输（不消耗轮数）
2. 超时（>60 秒）→ 提示重试（不消耗轮数）
3. 顾问违规 → 系统警告 + 终止
4. 顺序错乱 → 强制纠正
5. 客户偏题 → 顾问引导回主题

## 六、反思与改进方向

### 6.1 已知问题

- **中文场景下的违规检测**：关键词匹配（"保本""稳赚"）可能漏掉语义近似但用词不同的违规（如"肯定不会亏""绝对安全"）。改进方向：结合 LLM 自审或语义匹配。
- **6 轮限制的边界**：复杂产品（如结构性存款）可能 6 轮不足以解释清楚，强制结束会丢失关键信息。改进方向：允许"待续"状态而非直接终止。
- **客户偏题检测的误判**：基于关键词（"风险/费用/适合/购买"）的检测可能将"我担心市场波动"误判为偏题。改进方向：引入语义相似度阈值。
- **单次会话无记忆**：对话结束后状态不保存，无法复盘。改进方向：引入会话日志持久化。

### 6.2 设计反思

- **角色边界的必要性**：两个角色的禁止事项差异巨大，顾问偏向"不得承诺"，客户偏向"不得盲从"，这种镜像设计有效制造了对话张力，避免了"顾问说什么客户就听什么"的单向流。
- **停止条件优先级**：将"顾问违规"设为最高优先级（S5）是关键决策——金融场景下，顾问违规的代价远大于对话未完成，必须立即终止。
- **异常不消耗轮数的设计**：空消息和超时不消耗轮数，避免因系统问题导致用户轮数浪费，这是公平性设计。
- **OpenClaw 平台的限制**：OpenClaw 对中文 System Prompt 的理解依赖底层 LLM，不同模型表现差异大。改进方向：在 PRD 中标注"推荐模型"（如 GPT-4 或 Claude）。

### 6.3 改进方向

- 引入多产品对比模式（当前仅推荐 1 只）
- 加入"客户风险偏好测试问卷"前置环节
- 支持对话回放与评分（用于培训场景）
- 接入真实产品数据库（当前为模拟数据）
- 增加"合规审查"第三方角色（自动审查顾问发言是否违规）
