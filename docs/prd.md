## 1. 背景与目标

### 1.1 背景
作为深圳大学南特金融科技学院金融科技与风险控制硕士在读生，需要一个公开的个人网站，用于：
- 在求职季向招聘方展示专业背景与项目经历
- 在学术场合向同行展示研究方向与论文成果
- 在课程评估中作为模块三实验课的可交付作品

### 1.2 目标
- 建立一个**可公开访问**的静态个人主页（GitHub Pages）
- 完整呈现五区块（Hero / About / Skills / Projects / Contact）
- 严格遵守隐私红线，不出现手机号、身份证、住址、课程邀请码等敏感信息
- 满足模块三作业 G1–G6 六项硬性门槛

### 1.3 非目标（明确不做）
- 不做用户登录/注册
- 不做后端数据库与 API
- 不做评论、点赞、访客追踪
- 不做支付/电商
- 不放任何商业推广或第三方广告

## 4. 验收标准（Acceptance Criteria）

| AC 编号 | 描述 | 验证方式 |
| --- | --- | --- |
| AC1 | 五区块在首页均可访问（Hero/About/Skills/Projects/Contact） | 浏览器逐区块检查 |
| AC2 | 所有内容为本人真实信息，无模板占位文本 | 人工目检 + 关键词扫描 |
| AC3 | 桌面端（≥ 1024px）和移动端（≤ 414px）均布局正常 | Chrome DevTools 切换 + 截图 |
| AC4 | 任何位置均不出现手机号、身份证、邀请码等隐私字段 | 关键词正则扫描 + 人工核查 |
| AC5 | 所有外部链接可正常打开（GitHub、邮箱） | 逐个点击 |
| AC6 | GitHub 仓库为 Public，分支为 master | GitHub Settings 检查 |
| AC7 | 至少 3 次有意义的 Commit，提交信息描述清晰 | 仓库 Commits 列表 |
| AC8 | GitHub Pages 链接 `https://yinhy2008.github.io` 在无痕窗口可访问 | 隐私/无痕模式访问 |

## 5. 范围边界与变更控制

- 任何超出"替换真实内容 + 新建 Skills/Contact 页面"之外的修改，需在 Vibe 会话中重新确认
- 任何涉及隐私字段添加/修改的需求，必须由用户本人明确授权
- 任何对教师模板核心主题（Minimal Mistakes）的自定义样式扩展，需在 docs/design.md 中记录
